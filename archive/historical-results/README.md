# Archived historical results

English | [繁體中文](README_zh.md) | [Project guide](../../README.md)

These 37 figures were generated by this project's earlier analysis, before the source code and folder structure were reorganized. They are project results, so they are archived here rather than classified as external references. The cited research paper remains in [references/papers/](../../references/papers/).

| Location | Files | Contents |
|---|---:|---|
| [figures/decomposition/stocks/](figures/decomposition/stocks/) | 30 | Original stock decomposition plots |
| [figures/decomposition/etfs/](figures/decomposition/etfs/) | 4 | Original ETF decomposition plots |
| [figures/recurrence/](figures/recurrence/) | 2 | Original recurrence plots |
| [figures/portfolio/](figures/portfolio/) | 1 | Original six-stock MV frontier |

The decomposition plots retain their trend, seasonal, and remainder panels; the current pipeline's trend plots do not replace them. The historical 3711/2311 recurrence plot cannot be regenerated from the provided data because stock 2311 is absent. The original MV frontier records the earlier calculation and should be distinguished from the current refitted frontier.

[figure_manifest.json](figure_manifest.json) records each file's original path, previous `references/figures/` location, current path, size, and SHA-256. All 37 files were moved without changing their contents and checked against the [original cleanup record](../../docs/FOLDER_CLEANUP.json).

New analysis belongs in [outputs/](../../outputs/), and report figures belong in [reports/assets/](../../reports/assets/). Running the current pipeline does not overwrite this archive. These historical figures are separate from the 472 current analysis PNGs and six composite report figures.
